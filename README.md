# Daimonna 地址生成 · 一键自动填充

油猴（Tampermonkey）脚本：在任意网站一键调用 [address.daimonna.com](https://address.daimonna.com/) 生成真实格式的身份/地址信息，并智能填充到当前页面的表单。

支持生成 27 个国家/地区的地址：美国、加拿大、墨西哥、英国、德国、法国、意大利、西班牙、荷兰、俄罗斯、中国、香港、台湾、日本、新加坡、韩国、越南、泰国、菲律宾、马来西亚、印度、澳大利亚、土耳其、沙特、巴西、尼日利亚、南非。

## 一键安装

前提：浏览器已装 [Tampermonkey](https://www.tampermonkey.net/)。

点这个链接，油猴会自动弹出安装确认页，点「安装」即可：

**[➡ 一键安装 daimonna-autofill.user.js](https://raw.githubusercontent.com/seventhrainyday/daimonna-autofill/main/daimonna-autofill.user.js)**

装好后脚本会通过同一地址自动检查更新，不用重复手动安装。

## 使用

1. 打开任意注册 / 结账 / 收货地址页面（WHMCS 注册页有专门的精确字段映射，如 v6vps 等 VPS 商家）。
2. 点页面右下角的「🪪 地址填充」悬浮钮。
3. 选国家（可继续细选州/省、城市、区县、邮编）→ 点「⚡ 生成并填充」。
4. 快捷键 `Alt+Shift+F` 可直接生成并填充。

面板功能：

- **地点级联筛选**：国家 → 州/省（下拉全量加载）→ 城市 / 区县 / 邮编（可输入搜索的下拉框，数据来自官网 `locations/search` 接口，加州 1866 个城市也能搜）。不选即不限。
- **快捷地区**：与官网同源的快捷入口——特殊地区（美国为无州级销售税州）、快捷州/省、热门城市，点一下自动选好州和城市。
- **地址关键词**：填了之后生成的地址必须包含该文本（如 `Seattle`）。
- **住宅地址开关**：对应官网的住宅模式（中国默认开）。
- **按 IP 地区生成**：输入任意 IP（或留空用你当前 IP）先检测定位，再生成该 IP 附近地区的地址。
- **批量生成 ×5**：一次生成 5 套存入历史，挑一套点「填充」即可。
- **历史与收藏**：最近 10 套自动存历史；常用的一套可 ⭐ 收藏（上限 20），跨页面、跨重启保留。
- **生成并填充**：调 Daimonna 接口生成一整套新身份并填入表单，填上的字段会闪绿框提示。
- **仅生成预览**：不填表，只展示清单（含邮寄单行格式、Google 地图真实位置链接），点击任意一行可单独复制。
- **填充当前这套 / 复制全部**：同一套身份反复使用；或把姓名 / 地址 / 城市州邮编 / 国家 / 电话 / 邮箱一次复制走。
- **测试银行卡**：默认不填，勾选后才填卡号 / 有效期 / CVC（站点提供的测试数据，请勿用于真实支付）。

可填充字段：姓名（自动拆名/姓）、邮箱、电话、公司、街道地址、地址 2、城市、州/省、邮编、国家（下拉框自动选中）、生日、用户名、密码（站点有最低长度要求时自动补足，密码与确认密码保持一致）。

## 实现说明

- 数据直接来自 Daimonna 的同源免鉴权接口 `GET https://address.daimonna.com/web-api/v1/generate?country={国家代码}&strategy=instant`，无需打开该网站、无需 Token。
- 字段识别顺序：WHMCS 固定字段名精确匹配 → `autocomplete` 属性 → `name`/`id`/`placeholder`/标签文本正则匹配 → 输入类型兜底。
- 赋值使用原生 setter 并触发 `input`/`change` 事件，兼容 React / Vue 受控表单。
